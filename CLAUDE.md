# Instruções permanentes — Assistente pessoal

Lido no começo de toda sessão. Regras de processo, não conhecimento: o
conhecimento está no `README.md` e no `PLANO.md`.

## Comando para o dono rodar: escrever por extenso, sempre

Pedido explícito dele (21/09/2026, no projeto do CRM, e vale aqui). Nunca
"rode o comando de antes" ou "do mesmo jeito que da última vez": ele é leigo
em programação, e procurar comando em conversa rolada é onde o erro acontece.

1. Uma frase dizendo **em qual janela** rodar: a linha que começa com
   `root@` é o servidor, no PuTTY; a que começa com `Eload@Nena-pc MINGW64`
   é o computador dele, no Git Bash.
2. O comando **sozinho** no bloco de código, para copiar e colar sem editar.
3. Uma frase dizendo **qual resposta esperar**.

Copiar arquivo, mudar de pasta (`cd`), conferir backup: tudo é comando e
entra escrito por inteiro, na ordem. Comando que pode ser repetido sem
estragar nada é melhor que comando que falha na repetição.

## Ao terminar uma tarefa

Atualizar o `README.md` junto, em "Estado" e "Próximo passo". Decisão
importante vai para o `PLANO.md` com o **porquê**, não só o quê.
